Afghan Girls Build

A free web-development bootcamp created to introduce Afghan girls to programming and help them build their own websites.

2017First session described in the program history
KabulFirst-session location
FreeTuition described by the program

Opening a path into programming.

Afghan Girls Build introduced Afghan girls to web development through a free bootcamp. The original program website records the first session in Kabul in winter 2017.

The course covered HTML, CSS and JavaScript, with the aim of helping participants create a website by the end. Its published format ranged from two weeks to one month and included programming practice and guest speakers.

This project record preserves part of the education work shared with Dost’s archive. It describes the documented program, rather than announcing a current course or open enrollment.

Learning by making

  • HTML to structure a web page
  • CSS to style a website
  • JavaScript to introduce interactive behavior
  • A website project to put the lessons into practice

Historical program record compiled from the original website and public Facebook page. Current enrollment and the schedule of any future cohorts have not been confirmed.
